## Featured Projects

### 🛡️ [Network Security Compliance Auditor](https://github.com/Balrajukonne2629/SIH2026-PS155) · [Project site](https://balrajukonne2629.github.io/SIH2026-PS155/)
Smart India Hackathon 2026, NTRO problem statement PS26155. An offline, air-gapped auditor that checks network device configurations against CIS Benchmarks, DISA STIG and NIST SP 800-53. Rules are evaluated deterministically; AI only suggests mappings, and a human approves them. Every audit is written to a SHA-256 hash-chained log so tampering can be detected. Parses Cisco IOS-XE and Juniper Junos, generates CLI remediation, exports PDF and DOCX reports. Backend has 700+ automated tests.
`Python` `FastAPI` `React` `SQLite` `Docker`

### 🎫 [Customer Support Triage Environment](https://github.com/Balrajukonne2629/customer-support-env) · Meta PyTorch Hackathon 2026
An OpenEnv environment where AI agents learn to handle customer support tickets. Three tasks of increasing difficulty: ticket classification, priority and routing, and full ticket resolution. Exposes `/reset`, `/step`, `/state` and `/health` endpoints and ships as a Docker container. Baseline scores: 0.71, 0.68 and 0.52 across the three tasks.
`Python` `OpenEnv` `Docker`

### 🧭 [Agentic Career Companion](https://github.com/Balrajukonne2629/agentic-career-companion) · [Live demo](https://agentic-career-companion.vercel.app)
Career guidance app for engineering students. A 5-agent pipeline (validation, profile, career, skill gap, roadmap) turns a student's profile, by voice or text, into ranked career matches, missing skills and a 30/60/90-day roadmap. IBM Granite on watsonx.ai handles only the two language-heavy steps; the rest is plain Python. Falls back to local logic if the API is rate-limited or offline. 333+ pytest tests.
`React` `Vite` `Tailwind` `Flask` `IBM watsonx.ai`

Event management platform for college clubs, built with Sai Kushal M. Organizers create events and email faculty directly; students browse, search and register as teams. JWT auth with separate Organizer and Student roles. Released as v2.1.1.

### ⚖️ [BiasScope](https://github.com/Balrajukonne2629/BiasScope)
